# Task 5 — To-Do List Web App

A task management application built with HTML, CSS, and JavaScript.

## Features
- Add tasks
- Delete tasks
- Mark tasks as completed
- Filter by All / Active / Done
- Stats bar (Total, Pending, Done)
- Tasks persist after refresh using localStorage

## Tech Stack
- HTML
- CSS
- JavaScript
